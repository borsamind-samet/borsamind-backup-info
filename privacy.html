BORSAMIND-YEDEK

Privacy policy

BorsaMind-Yedek is an owner-operated personal backup utility. This policy describes the Google Drive integration and this informational website.

Google data and permissions

The integration requests only the drive.file OAuth scope. Google limits this scope to files created by the app or explicitly made available to it by the user. BorsaMind-Yedek's backup workflow is limited to files and folders it creates; it does not ask the owner to select unrelated existing files.

The integration uses backup file contents and associated metadata, such as file identifiers, sizes and checksums, to upload, verify, list, restore and manage those backups. It does not request access to Gmail, contacts, calendars, or the entire Drive.

Storage and security

Backup archives are encrypted before upload. Encrypted archives are stored in the owner's Google Drive. OAuth credentials, refresh tokens and encryption material are kept in restricted storage on the owner's systems, not on this website or in its public source repository. Operational records may contain backup status and metadata; they must not contain OAuth secrets or decrypted backup contents.

Use and disclosure

Google Drive data is used only to operate this backup and recovery workflow. It is not sold, used for advertising, or sent to AI services for model training or analysis by this integration. Google processes uploaded data as the selected storage provider. BorsaMind-Yedek's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, revocation and deletion

The owner controls backup retention and deletion. Revoking access through the Google Account's third-party connections stops future authorized access but does not automatically delete existing backups. The owner can delete backup files from Drive and remove locally stored tokens and configuration. Local restored copies and local backup copies must be managed separately.

This website

This static site includes no application analytics, advertising, login form, or custom tracking scripts. Its hosting provider, GitHub Pages, may process ordinary web request information under its own privacy statement.
