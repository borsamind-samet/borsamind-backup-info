PERSONAL BACKUP UTILITY

BorsaMind-Yedek

Private, encrypted backups to the owner's Google Drive.

BorsaMind-Yedek is a personal backup integration operated by its owner on a private Ubuntu server. It uses rclone to upload encrypted backup archives to the owner's Google Drive account. It is not offered as a public service.

Limited Drive access

The integration requests only https://www.googleapis.com/auth/drive.file. Its intended workflow creates and manages its own backup files and folders. It does not request full-Drive access, Gmail access, or access to contacts and calendars.

What this website contains

This website provides application and privacy information only. It does not provide access to the private application, its dashboard, backup contents, account records, or credentials. It has no sign-in form.
